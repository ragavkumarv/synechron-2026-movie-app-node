# Simple movie backend

Express + MySQL CRUD for `synechron-2026-movie-app-react`, using ES module imports and dotenv.
Requires Node.js 22+ and a running MySQL server.

```sh
npm install
cp .env.example .env
```

Set your MySQL credentials in `.env`. Keep your existing `.env` if it is already configured.
Create the database, table, and 11 sample movies using the MySQL CLI:

```sh
mysql -h 127.0.0.1 -P 3306 -u root -p < database.sql
npm start
```

Enter your MySQL password when prompted. Use the host, port, and username from `.env`.
You can also execute `database.sql` in MySQL Workbench. It creates `synechron_movies_node`;
if you change `DB_NAME`, update the two database references in the SQL file too.
Rerunning the SQL skips existing movie ids and preserves edits. Normal server startup
only checks the connection/table; it does not run the seed again.

The API defaults to port 4000. Change `PORT` in `.env` if it is occupied.
Use `npm run dev` for automatic restarts when JavaScript files change.

The backend uses five JavaScript files:

```text
index.js                         Express setup, errors, and server startup
config/database.js               dotenv settings and MySQL connection pool
routes/movie.routes.js           Endpoints and basic validation
controllers/movie.controller.js  HTTP requests and responses
models/movie.model.js            SQL queries
```

`database.sql` contains both the schema and sample data. No ORM or validation package is needed.

| Method | Endpoint | Action |
| --- | --- | --- |
| GET | `/api/movies` | List movies |
| GET | `/api/movies/:id` | Get one movie |
| POST | `/api/movies` | Create movie (201) |
| PUT | `/api/movies/:id` | Update movie |
| DELETE | `/api/movies/:id` | Delete movie (204) |

POST and PUT accept the same JSON fields:

```json
{
  "name": "Vikram",
  "poster": "https://upload.wikimedia.org/wikipedia/en/9/93/Vikram_2022_poster.jpg",
  "rating": "8.4",
  "summary": "A black ops team investigates a series of murders.",
  "trailer": "https://www.youtube.com/embed/OKBMCL-frPU"
}
```

Validation only checks required text (`name`, `poster`, `summary`), a name up to 255 characters,
a rating from 0 to 10, an optional trailer string, and a positive integer id.
Ratings accept numbers or React form strings. Movie ids are generated by MySQL and returned
as strings. Invalid input returns 400; missing movies return 404. SQL values use placeholders.

Run the integration tests against your local MySQL server:

```sh
npm test
```

Tests use credentials from `.env`, create a randomly named temporary database, and remove it
afterward. The test account needs permission to create/drop databases. Tests cover the SQL seed,
CRUD, validation, CORS, and persistence after restarting the server.

To connect the React app, replace `https://6971d50b32c6bacb12c4aa19.mockapi.io/movies`
with `http://localhost:4000/api/movies` in `src/MovieList.jsx`, `src/AddMovie.jsx`, and
`src/MovieDetails.jsx`, keeping the `/${id}` suffix where present. Use your configured port.
CORS is enabled for browser requests.
