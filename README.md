# Simple movie backend

All backend code is in `index.js`: Express + MySQL CRUD for `synechron-2026-movie-app-react`.
Requires Node.js 22.9+ and a running MySQL server.

```sh
npm install
cp .env.example .env
# Set your MySQL username/password in .env, then:
npm start
```

The server creates `synechron_movies_node` and an empty `movies` table automatically.
The MySQL user needs permission to create the database and table. Existing data is preserved.
Use `npm run dev` to restart automatically when `index.js` changes.
If port 4000 is occupied, set another `PORT` in `.env`.

| Method | Endpoint | Action |
| --- | --- | --- |
| GET | `/api/movies` | List movies |
| GET | `/api/movies/:id` | Get one movie |
| POST | `/api/movies` | Create movie (201) |
| PUT | `/api/movies/:id` | Update movie |
| DELETE | `/api/movies/:id` | Delete movie (204) |

POST and PUT accept JSON with `name`, `poster`, `rating`, `summary`, and optional `trailer`:

```json
{
  "name": "Vikram",
  "poster": "https://upload.wikimedia.org/wikipedia/en/9/93/Vikram_2022_poster.jpg",
  "rating": "8.4",
  "summary": "A black ops team investigates a series of murders.",
  "trailer": "https://www.youtube.com/embed/OKBMCL-frPU"
}
```

Movie ids are generated by MySQL and returned as strings. Ratings accept numbers or React form
strings from 0 to 10. PUT requires the same fields as POST. Invalid input returns 400;
missing movies return 404. Data persists across server restarts.

To connect the React app, replace `https://6971d50b32c6bacb12c4aa19.mockapi.io/movies`
with `http://localhost:4000/api/movies` in `src/MovieList.jsx`, `src/AddMovie.jsx`, and
`src/MovieDetails.jsx`, keeping the `/${id}` suffix where present. Use your configured port.
CORS is enabled for browser requests.
